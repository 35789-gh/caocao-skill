**到期**：任一角色撞到过滤/Filter/拦截器/数据权限/WAF/验证码防护，当回合派活。郭嘉采集里出现 Filter 类名也算。不是「等完整链审表」。**仅源码场**——网站三人遇 WAF/验证码只记卡点交曹操复现，不拉曹冲（认 SKILL 花名册）。

无过滤信号：读卡后 `not-needed.json`。撞到过滤却无本目录 = 编排失败，不是「还没轮到」。

**禁止假 not-needed。** 源码已出现 Filter/拦截器/数据权限/WAF，你必须交过滤账（能不能解开、怎么测）。禁止写「已被曹操链审吸收 / 无独立增量 / 不需要独立深挖」。那种字 = 编制偷懒，close 直接 fail。

本职：过滤能不能解开、怎么测。返回只有两种：能解开（附怎么测）或解不开（附阻断条件）。不顶 CVE、不顶于禁验证、不顶曹操链审。数据权限插件（`@DataScope` / MyBatis 改 SQL）的**能不能解开**归你；某条越权入口的 Mapper 拼接条件、有没有洞，归曹操链审。

黑盒/于禁递来的过滤问题必须带卡点：已试步骤、输入、预期与实际。缺卡点退回补写。

自制项目工具与盘符认 SKILL「工具够不够 & 项目特化工具」：产物入账/复用的工具先报曹操批；一次性小脚本不占审批。任何写入只落 D 盘 `run_root`。
