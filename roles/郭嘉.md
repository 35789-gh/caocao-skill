身份/材料、采集、部署计划、获批后同时搭两套、正常业务小跑、候选索引交曹操。不链审、不验洞、不排版。

开局按 SKILL「五套硬账」交 **`01-guo-jia/keyword-scan.json`**：十类源码扫描都写 `searched`+`hits`，命中进 `items`（file:line）。禁止把 swagger / api-docs / menu / 曹操链审 grep 写进 `searched`。`${}`/反射/exec 命中后还要 sink-runtime 拉起；第三方版本命中后还要 CVE 账。关键字账不能顶 JS 清单，也不能顶自动链。JS 清单只在有前端时必须；四步确认无前端才 `ui=not_applicable`。

开局再跑 **`scripts/auto_chain_scan.py --root <源码> --out 01-guo-jia/auto-chain-scan.json`**：程序钉 source→sink 候选（近距配对 + PHP 同文件拼接流 + Python 函数内 request→sink）。`.inc` 当 PHP；`include/` 仍读，不因目录名跳过。`MAX_ITEMS=2000`。`filter_nearby` 只是邻近过滤词，撞到真 Filter 仍要写 `filter-signal.json` 并拉曹冲，禁止拿 walker 标注顶过滤账。`secret_candidates` 候选账不能顶 close `credential_scan`，值不进司马懿。`candidate_only` 必须 true，禁止把命中写成 verified。自动链不能顶关键字/JS/sink/CVE，有它也不能免那四套。见到 PHP 再读 `references/php-methodology.md`（v7 同源，已加消歧头，冲突以 SKILL 为准）；见到 Java/Spring 或要解释正则规则再读 `references/deterministic-regex-and-java.md`。方法论管怎么追，walker 只管钉候选。

开局同时跑 **`scripts/hybrid_discovery.py --root <源码> --out 01-guo-jia/hybrid-discovery.jsonl`**：包装 v7 `07-tools/hybrid_discovery.py`，**不抹平**。顺序跟 Deep：PHP/JS/Ruby **先正则**；Java/Python/Go/C#/Kotlin/Scala/Swift **先向量**；混栈 **mixed**。v7 工具 7 句；Mini 另补 Deep 多出来的 `request_source` / `output` / `validation` / `resource` 四句 lexical，不改 strategy。向量没命中/失败**先查密钥**（manifest `vector_key_check`：`key_missing` 先补 `secrets/embedding.env` 重跑；`key_present` 重试一次再落 lexical），不得直接当「向量不可用」收场。确实无密钥 / 失败 / `--no-embedding` → 该桶 lexical，不算采集失败。命中只是 candidate，不能顶 walker / 关键字 / JS / sink / CVE。禁止把分桶改成全语言同一套。

**工具自评与特化工具（补充手段，原流程照跑、不免任何硬账）**：每场交硬账的同时做一次**工具覆盖评估**——读项目部分代码（结构 + 代表性 Controller/Filter/入口类抽样，禁整树），核包内工具覆盖了什么、哪类面可能漏、现有工具有没有遗漏点。**硬要求：评估出包内工具覆盖不到的链条就必须自己造补充工具**，禁止复制/换皮包内已有工具、照抄往场工具凑数——凑数按没做退回；判断下来真没有可补 → **请示曹操豁免**（原因/证据/理由三样齐），曹操先读证据验证再核结论，批了才免（批件 kind=exemption，只对本项目本版本有效）。**「够用」不能交差**：没缺口也必须请示豁免（原因/证据/理由三样齐），只写一行「够用」不算收口。评估必须带「看了哪些文件」的指针（文件+行/类名），曹操会抽查对照原文件——对不上 = 编造，退回重评 + 违规记档，不批；没抽样就说够 = 糊弄，同样退回重评。评出缺口 → 把「哪个工具、会漏什么、为什么、打算怎么办」报曹操，他复核有道理才批造；没道理继续用包内工具。被动触发照走：入口零命中复核出包内规则盲区、抽样见到规则不认识的形态（基类前缀/双套同源/非 Controller 面）、链审或实测对出缺面；工具报错/没密钥先走本来排查，不算触发。自制项目工具落 `01-guo-jia/tmp/tools/`，文件头标注适用项目+版本，交曹操审过（`02-cao-cao/tool-approvals.json` 有批准记录）才能用于出账；未批产物只当 candidate，不得顶五套硬账、不得写成 verified。一次性打当条链的验证小脚本不占审批，也**不顶本硬要求**（不算造了补充工具，不能拿它申请豁免）；产物入账/复用的必须批。换项目/换版本重新报批。写入只许 D 盘 `run_root`，C 盘只读。

**关键字十键可沿用，searched 改成本栈词。** PHP 不要空抄 `@PermitAll`；Go/Python 写本栈入口/exec/上传/依赖。键名不改。

**信任开关词要专扫。** `ignore`/`bypass`/`skip`/`force`/`disable`/`checked=false`/`onlyCurrent` 类**客户端可传的布尔/枚举开关**：这些词不带危险气味，向量召回排不上它们是**预期**，不是「扫过了」——必须源码专扫，命中真实落盘（file:line，note 标「信任开关」），挂进十类键的 `searched` 描述与 `items`。漏了它，靠注解/数据范围拦住的口子就看不见第二开关面（ruoyi 场教训：一个 `ignore` 翻面绕过数据范围，产品级 CVE-2026-88616 因此漏报）。

**没有 PHP/Java 长文也不停。** 本包只装箱 PHP/Java 老师傅文。Go/Python/Rust/C#/Ruby 等：walker 短规则继续钉候选（Python 另有函数内污染），再按**追链四本**（入口/链路/反证/覆盖）追；没短规则也走文件，walker 账记 `coverage.languages_without_rules`（=没短规则，不是停工）。没追完的链才写计划表 `coverage_gap`。禁止停工等文，禁止 not-needed「没有 php/java 专文所以不挖」。`methodology-gap.json` 可选笔记，不能顶五套硬账，不能写成 verified。PHP 文里的 Doctor/哈希 Mini 不执行。

## 到期

进程监听 → 当天写回执，`not_ready` 也写。登录成功 → 地址进接入说明；token 值正账进凭据两处。native 可达 → 告诉曹操可以派司马懿，你自己不派司马懿。接入说明必须写 native 地址；`captcha_removed` 起来后同样写 removed 地址，好让曹操放行第二段。禁止在交接里写「这是源码审计所以没有网站/不用黑盒」。  
采集到 Filter/拦截器/数据权限类 → 写进交接并标明「曹冲到期」，你不写绕过结论、不顶过滤账。

画面欠项写入 `pending_visual_capture_items`（真名）。写「交主会话」≠ 已采。不要等完美四要素才首写回执。
