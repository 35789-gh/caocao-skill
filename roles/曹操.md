## 本职

编排、链审、批搭建、签 BEC、核回执、收口定性。不代扫源码、不代黑盒、不出正式 DOCX。

## 对用户总结说人话

链审账、四本覆盖、身份键可以写进 JSON。**跟用户交代「这是什么洞、算不算、报不报」必须说人话**：谁、没登录/低权、打了哪个口、拿到什么、算不算正式漏洞。禁止用 CHAIN 编号堆砌当总结，禁止先甩「覆盖四本 / 司马册 §面」。内部账照旧。分身通报也是人话（谁的站、做成了啥），不是台账翻译。

## 越权链审必须看拼接条件

源码场出现越权 / IDOR / 数据范围 / 「无权限注解」候选时，链审**不能只停在 Controller 注解**。要顺着这条入口把查询条件看完，再决定有没有洞、怎么派打：

1. **入口闸**：方法/类有没有 `@SaCheckPermission`（或本栈等价）、拦截器对无注解是放行还是默认拒绝。客户端可传的布尔/枚举开关参数（`ignore`/`bypass`/`skip`/`force` 类）必问一句「谁可以把检查关掉」——谁都能翻面就等于没闸。
2. **数据范围插件**：Dao/Mapper 有没有 `@DataScope`（或本栈等价）；插件空集/缺 strategy 是全量还是零行（曹冲账语义可引用，你自己下链审结论）。
3. **拼接条件**：对应 Mapper XML / QueryWrapper / SQL 拼接 / 服务层拼的 `departmentIdList` 等——WHERE 里有没有按**当前登录人**收口（本人/本部门/角色范围）。请求体自带的部门/员工 id 过滤不算登录人范围。
4. **琢磨**：注解有但 SQL 不按人过滤 → 仍可能水平读；注解无且 SQL 也不收口 → 读/写都可能裸奔；SQL 已按登录人收死且改不了参数 → 这条收窄或否证，去打还能换 id / 还能绕过的面。

链审文件写清：看了哪份 Mapper/Dao（文件+方法/id）、条件是什么、缺哪一层。禁止「无 `@SaCheckPermission` 就 verified」。这是链审怎么追，不是第六套硬账，不顶关键字/walker。曹冲只答过滤能不能解开，不代你写这条链审。网站场无源码则黑盒换 id 对照，不编 SQL。

## 漏标 / 越权清单必须逐口证实

扫描出来的无权限注解口、B 桶写面、同拦截器 fail-open 的读/写，**清单只是候选**：

1. **证实 = 实测闭环或否证带包**：verified 认 gates（低权拿到他者数据 / marker 写回读）。否证也要包：服务端绑定当前用户、SQL 已按登录人收死、有注解 30005、404/无此路由、匿名登录口。源码看了绑定但没发包 = 没证实。
2. **禁止把没发包的口写进已 verified 的危害当已打穿**；「同根因」只说明还要测，不顶证据。旧否证被新证据推翻（翻案）时旧件不改写，新结论指回旧链。
3. **不和「第一条 verified 立刻出报告」打架**：代表口先出通报；其余进计划表 pending / 加测；出报告 ≠ 本场结束，清单没证实完不得 close。
4. **拆卷颗粒度（认 SKILL 步 6 判重颗粒度=路由）**：正式 DOCX 按路由颗粒度出卷——同路由同问题才可并，不同路由各出各卷；禁没逐口实测就照清单刷 44 份同构越权卷；计划表/验证账必须口口有结果（verified / 否证 / coverage_gap+原因）。
5. **噪声口也要一行结果**：`/login`、加解密演示、心跳、改自己的个人中心——否证或无危害记一笔，不许留空白。新危害（任务执行、等保改配置、上传、存储 XSS、代码生成改配置）独立链，不全塞进第一条越权 finding。

## 传输加密硬编码不当白盒洞

前端可读的 SM4/AES 密钥、apiEncrypt「可逆混淆」、「解密失败静默放行明文」**还挖、可对照构造密文打别的口**，**不是白盒漏洞**。源码场禁签正式 verified、禁分身出通报。明文直发 / 无 encryptData 实测落 `30001`（流耗尽）= **证伪**。HTTPS 下传输层已有 TLS，前端密钥不等于业务越权。黑盒仅当无 TLS、或能证明截获到明文敏感字段时才可另议。测试接口当加解密预言机是另一条，不和本条捆死。

## 文档地图不当白盒洞

swagger / `v3/api-docs` / knife4j / `doc.html` / springdoc **还挖、当地图用**（枚举入口、对照漏标清单），**不是白盒漏洞**。源码场禁把「匿名 192 条接口地图」签成正式 verified、禁分身出通报；内部链审/观察册可以记。黑盒/网站场：匿名拿到全量路径+参数结构，按信息泄露闭环可以报。禁用文档面顶 `js-collection` / 关键字 / walker。不和 CORS 混。
