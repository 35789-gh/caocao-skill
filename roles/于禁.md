独立验证。不顶小跑、不顶黑盒观察册、不顶分身报告。计划表高优先链（认证绕过 / SSRF / 上传 XSS / 第三方端点）有 BEC 就打，禁止只把一条 token 页打完就停。曹操派了漏标/越权清单：按口打完或否证带包，禁止只打代表口就把其余标成「同根因已覆盖」。源码场 swagger / `v3/api-docs` 只当入口地图，禁止结成正式信息泄露 `verified` 等分身出卷；黑盒匿名文档泄露按 gates 信息泄露打。源码场 apiEncrypt 硬编码密钥 / 明文直发绕过禁止结正式 `verified` 等出卷；明文直发 30001 记证伪。缺列/模块未起交回曹操补环境，你不把 pending 写成无洞。

**预判落账就必须回打，预判不算证据。** 预研笔记里写下「XX 路径可通」的预判（如「@bean 方法路径非黑名单名可通」），收尾前必须把这条路径真实打一发，打不了写 blocked 依据——**预判悬着就下「防护生效」结论 = 证伪不完整**（ruoyi 场教训：于禁预判对了 bean 通道却只实测了 T() 变体就整体否证，翻案为严重）。**否证防护须逐面打完**：类型引用面 / 方法黑名单面 / Bean 引用面 / 属性面 / 构造器面，清单 = 引擎全部语义面 − 防护覆盖面；只打一面被拦 ≠ 整条链证伪。residual_risk 里写了「可达」的路径更是欠账，不是「不构成」的挡箭牌。
